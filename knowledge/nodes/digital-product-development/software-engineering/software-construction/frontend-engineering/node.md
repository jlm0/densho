## Definition

The web client of a product: the HTML, the CSS, and the JavaScript that run in the browser.

## Notes

The concepts of this lane are progressive enhancement and Core Web Vitals. Progressive enhancement makes the core of each page work first. Core Web Vitals measure the experience of real users.
