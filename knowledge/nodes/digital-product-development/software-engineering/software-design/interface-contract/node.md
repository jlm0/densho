## Definition

A machine-readable description of an interface, which a consumer reads to call the interface without its source code. The OpenAPI Specification describes HTTP APIs in a form that is independent of the programming language. The AsyncAPI Specification describes message-driven APIs over any protocol, such as AMQP, MQTT, WebSockets, or Kafka.
