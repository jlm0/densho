# Payment provider codes

| Code | Meaning | Message key |
| --- | --- | --- |
| 14 | The card number fails the check digit test. | `card_number_rejected` |
| 54 | The card is past its expiry date. | `card_expired` |
| 51 | The account does not hold enough money. | `funds_insufficient` |

The shop checks the postcode itself. A postcode has 5 digits.
