# Human interface

> **In the library:** the reading room, where people browse and review the same books the visitors use.

**Status:** Planned. Nothing on this page exists yet.

## What it does

This layer will add views and review tools for people. Agents and people read the same source, so this layer is another consumer of the knowledge. It adds no new knowledge of its own.

## How it works

The design does not exist yet. Until it does, a node is a Markdown file that any editor can open and Git can review.

## How it fits

People and agents are two consumers of one source. This layer reads the same nodes that the [runtime files](runtime-files.md) come from, so it cannot show people a different version of the knowledge.
