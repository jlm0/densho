## Inputs

- The strategy section of the brand guidelines
- The current brand assets: the logo files, the colors, the typefaces, and samples of their use

## Procedure

1. Write the logo section: each lockup, the clear space, the minimum sizes, the color versions, and the misuse examples.
2. Write the color section: the palette with the values for each medium, the role of each color, and the light and dark values of each role. Check the contrast of each pair of a container role and its content role.
3. Write the typography section: the typefaces, the type scale with its base and its ratio, and the text styles by role.

## Output

The logo section, the color section, and the typography section of the brand guidelines.

## Exit gate

Check the sections against each directive of this step and of the skill, and report each one that it misses. Each pair of brand colors for text or controls passes the contrast rules.
